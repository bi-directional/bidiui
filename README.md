# bidiui

**bidiui** is an upcoming **headless React UI utilities library** designed for apps that need **true RTL + LTR support** with minimal hassle.

This project will provide React-friendly direction helpers, primitives, and patterns so components naturally adapt to both text directions — without enforcing styles or design systems.

> 🚧 **Early work in progress** — this repo marks the start of the effort.  
> Goal: make building fully bidirectional React UIs *simple and predictable*.

## Vision

- ✅ Seamless RTL + LTR support
- 🔁 Minimal code changes to enable RTL
- 🧠 Headless — BYO styling (Tailwind, CSS-in-JS, etc.)
- ⚛️ React-focused direction context + hooks
- 🪶 Lightweight and dependency-free core
